AI RAG-Based Teaching Assistant

An AI-powered teaching assistant that uses Retrieval-Augmented Generation (RAG) to answer questions based on educational video content.

Features

Extracts audio from educational videos.

Processes speech into searchable text.

Splits content into chunks and creates embeddings.

Retrieves relevant content for user questions.

Generates context-grounded answers using AI.

Technology Stack

Python

Whisper for speech processing

Ollama for embeddings and language model inference

Retrieval-Augmented Generation (RAG)

Project Status

Developed as an educational AI project.

Note

Running the complete application may require locally installed models and additional dependencies.
